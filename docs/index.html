GRIT-Echo: Uncertainty-Gated Segmentation for Echocardiography

A reproducible investigation of whether prediction entropy can identify unreliable cardiac segmentation before it reaches a downstream clinical measure.

Abstract

Making segmentation reliability explicit

Deep segmentation systems can produce plausible-looking contours on low-quality ultrasound frames while providing no indication that the result should be reviewed. GRIT-Echo studies a simple reliability signal: normalized Shannon entropy from a U-Net posterior.

The system segments the left ventricle, myocardium, and right ventricle in 2D echocardiograms from the CAMUS benchmark. Entropy is measured frame by frame and calibrated on validation data into three information granules—crisp, vague, and artifact-prone. The held-out analysis tests whether these granules track expert image quality and whether their burden predicts segmentation and LVEF error.

Entropy separates the CAMUS quality grades (Kruskal–Wallis p = 1.7 × 10−5, ε2 = 0.222). Artifact-prone burden correlates with per-sequence Dice (Spearman ρ = −0.543, p = 5.4 × 10−9), and excluding flagged sequences increases mean Dice from 0.893 to 0.919.

Research questions

Study objectives

RQ1 · Quality association

Does frame-wise prediction entropy, summarized as three granules, track CAMUS image-quality labels: Good, Medium, and Poor?

RQ2 · Error prediction

Does uncertainty predict segmentation and LVEF error on held-out patients, and can it support an automatic review gate?

Methods

Patient-level, geometry-aware evaluation

The pipeline uses the official CAMUS patient split and keeps model selection, entropy calibration, and test evaluation separate. Every test result is produced with deterministic inference and is reported at the sequence level where appropriate.

01

Cohort audit

Verify image and mask availability, metadata, and the official 400 / 50 / 50 train, validation, and test split.

02

Segmentation

Train a four-class U-Net with a ResNet-34 encoder using Dice plus cross-entropy, augmentation, AMP, and early stopping.

03

Clinical endpoint

Estimate LVEF using the Simpson biplane method of disks from predicted and expert masks with native voxel spacing.

04

Uncertainty

Compute normalized Shannon entropy over posterior probabilities for every frame and over predicted tissue pixels.

05

Granulation

Freeze tercile cut-points on validation entropy, then assign identical crisp, vague, or artifact-prone labels to test frames.

06

Statistical analysis

Use Kruskal–Wallis, corrected Mann–Whitney comparisons, Spearman correlation, effect sizes, and risk–coverage analysis.

Design safeguards

  • No patient leakage: train, validation, and test identifiers are checked for overlap.
  • Validation-only calibration: granule cut-points are not fitted on test data.
  • Geometry preservation: letterbox padding avoids aspect-ratio distortion before resizing.
  • Native spacing: HD95 and volume calculations use per-header voxel spacing.
  • Declared uncertainty: effect sizes accompany significance tests.
  • Deterministic scoring: fixed seeds, evaluation mode, and argmax decoding are used.

Principal finding

Uncertainty is not treated as a decorative confidence score. In this experiment, high artifact-prone burden identifies sequences with lower segmentation quality and can produce a prioritized review list.

Interpretation: gating improves the accuracy of the retained cohort; it does not claim that flagged scans can be safely ignored.

Scope and limitations

This is a single-dataset study using CAMUS labels and a fixed U-Net configuration. The gate is a decision-support mechanism, not a substitute for clinical review or external validation.

The LVEF offset against the clinical reference reflects implementation differences in volume estimation; expert-mask comparisons are the primary endpoint.

Reproducibility

Open implementation and execution path

The repository contains the package implementation, unit tests, and a Kaggle-ready notebook. Paths automatically support Kaggle or local execution and can be overridden with GRIT_NIFTI, GRIT_SPLIT, GRIT_SEQ, and GRIT_WORK.

git clone https://github.com/iftekharalamfahim/grit-echo.git cd grit-echo pip install -e ".[dev]" pytest grit-echo audit grit-echo run --stages audit,seg,eval,rq

The reference environment is Python 3.12.13 with PyTorch 2.10.0, CUDA 12.8, NumPy 2.0.2, and an NVIDIA Tesla T4 on Kaggle. A full notebook run takes approximately 40 minutes, primarily for training.
